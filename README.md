# ShopZone — E-Commerce UI Clone

A front-end e-commerce website inspired by Amazon, built using HTML, CSS, and JavaScript. ShopZone provides a clean shopping interface with product listings, category filters, search functionality, and an interactive shopping cart.

## Project Overview

ShopZone is a front-end web development project designed to demonstrate core web development skills, responsive layouts, DOM manipulation, and JavaScript functionality.

## Features

- Modern e-commerce homepage and navigation bar
- Product search functionality
- Category-based product filtering
- Product cards with ratings, prices, and discounts
- Add-to-cart functionality
- Shopping cart sidebar
- Remove items from the cart
- Automatic cart total calculation
- Checkout demonstration with notification messages
- Hover effects and interactive UI elements

## Technologies Used

- HTML5 — Website structure
- CSS3 — Styling, layout, transitions, and responsive grid
- JavaScript — Search, filtering, cart management, and UI interactions

## Product Categories

- Electronics
- Fashion
- Books
- Home & Living
- Sports

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional dependencies or installation are required.
